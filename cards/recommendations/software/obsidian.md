# Obsidian

I discovered Obsidian thanks to [-Spanish Video- Alva Majo . 7 meses usando Godot ¿Me arrepiento?](https://youtu.be/DZqYvo3ZqYw?si=uwXW18NZWHvCj04Q&t=69) shows how the YouTuber used the app to take notes and learn the differences between Godot and Unity.

Obsidian is really one of the most important apps in my life; I have been using it to manage projects, journal, save-record things to remember, and a lot more simple things. But essentially what I like about Obsidian is that it is simple and easy to implement in my workflow. Taking notes in general helps me a lot to know me better and learn how I am comfortable managing + saving information.

A fun fact is that this web (cards, loading text - images) is just Markdown files that I edit totally with Obsidian. ^^

I really recommend Obsidian for basically anything, especially if you're searching for a simple note-taking app. Thanks to the community, we have the possibility to install any plugin/theme that could help us using Obsidian, even the most niche thing.

You don't reallyyy need to make a big use of Obsidian, though, like, it doesn't need to be or shouldn't be your life savior on the first day. I recommend not thinking too much about if it's worth using it or not, especially if you aren't really into note-taking in the first place.

If you're new, I recommend just installing and using the app for anything that you think is useful for you:

- doing your homework there
- using notes as a todo list for the day
- saving good-useful things for later use


I DON'T RECOMMEND checking the community or the "Obsidian Customization Rabbit Hole" that's inside YouTube or some places in Reddit, this could be a big problem for you as a user because the community tends to really over-complicate the use of Obsidian in all contexts. This is why I recommend just installing the app, and if you need anything special / have an idea of something that you would like to do, I recommend going to the official Discord or check the [Kepano's way to use Obsidian (Creator of the app btw)](https://stephango.com/vault)
