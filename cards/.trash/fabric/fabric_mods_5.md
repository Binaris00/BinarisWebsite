# Fabric Mods (5)

### Multihitboxlib (Fabric Port)

Multihitbox lib is a library for handling advanced multihitbox mobs, Syncing hitboxes with geckolib bones too (and with Azurelib). This is made for handling easy multipart entities and making complex geckolib animations easily.

In this case I was asked to make the Fabric port of the 1.20.1 version.

Check more on: [[multihitbox_lib|MultihitboxLib]]

### Odyssey Pokedrop

Adds a new custom system to add drops to the Pokemons, with a Pokémon whitelist and supporting item nbts and multiple World loader. Mod made to work with Fabric-Spigot plugins.

Check more on: [[odyssey_pokedrop|Odyssey Pokedrop]]
