# Fabric Mods (6)

### Sad Ditto

This mod's purpose is to prevent the "Bottle Cap" items from the `cobblemon utility` mod from being used on Ditto. Made to avoid broken Dittos inside the server due to this mod.

Commission made for Dystopia Network (Minecraft server)

Check more on: [[sad_ditto|Sad Ditto]]

### Shiny Converter

Add a new GUI to change your shinies into custom items (NBT data support), config for changing GUI placement, text format and different Pokémon checks.

This mod was made for Fabric and Forge for Minecraft 1.20.1.

Check more on: [[shiny_converter|Shiny Converter]]
