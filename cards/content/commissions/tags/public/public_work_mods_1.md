### Public Work Mods

Mods that are free for everyone, including the source code.

### Biome Loot Table

Dev test for Eufonia Studio a while ago.

Changes how the loot tables are being handle by the game. Adding server side configs for modifying loot depending on which biome the player at that moment, also giving the possibility to select the loot table based on a config list.

Check more on: [[biome_loot_table|Biome Loot Table]]

### Exploration Revamped

Adds several QoL features related to exploration and movement around your world. Trying to change a lot of mechanics and day to day features of the original game, specially focused on adding new items, crafting recipes and overriding default mechanics.

Check more on: [[exploration_revamped|Exploration Revamped]]
