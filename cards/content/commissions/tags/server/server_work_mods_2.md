# Server work mods (2)

### Odyssey Pokedrop

Adds a new custom system to add drops to the Pokemons, with a Pokémon whitelist and supporting item nbts and multiple World loader. Mod made to work with Fabric-Spigot plugins.

Check more on: [[odyssey_pokedrop|Odyssey Pokedrop]]

### Sad Ditto

This mod's purpose is to prevent the "Bottle Cap" items from the `cobblemon utility` mod from being used on Ditto. Made to avoid broken Dittos inside the server due to this mod.

Commission made for Dystopia Network (Minecraft server)

Check more on: [[sad_ditto|Sad Ditto]]
