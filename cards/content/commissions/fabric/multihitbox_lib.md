### Multihitbox-Lib (Fabric Port!!)

(Commission made for AzureDoom)

Multihitbox lib is a library for handling advanced multihitbox mobs, Syncing hitboxes with geckolib bones too (and with Azurelib). This is made for handling easy multipart entities and making complex geckolib animations easily.

In this case I was asked to make the Fabric port of the 1.20.1 version.

This is still in an early state, so the Fabric version published yet, but you can check my work [here](https://github.com/DerToaster98/MultiHitBoxLib/commits/1.20.1-Fabric)
